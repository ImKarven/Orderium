## Fixes
- `order-complete` webhook does not do anything.
- Possible `IndexOutOfBoundsException` when using certain configuration of your orders GUI.

## Feats
- Placeholder `deliver-amount` is added to `deliver-order` webhook, allowing you to specify the amount of items the player delivered.

## Misc
- packetevents is no longer required for Orderium to work.
- 1.21.7 is no longer supported.

An experimental documentation website is created. Check it out: https://orderium.github.io/.
