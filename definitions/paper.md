# Paper
Information: https://papermc.io/software/paper/

## Server
"Server", "the Server" or "your Server" is the [Java virtual machine](https://en.wikipedia.org/wiki/Java_virtual_machine) running Paper that you use to run Oderium on.

## Paper API
Paper provides Paper API. Paper and Paper API let Paper plugins run on the Server and do what it is supposed to do.

## Plugin
"plugin" or "Paper plugin" is a software that interacts with Paper API.
<br>
Information: https://docs.papermc.io/paper/dev/how-do-plugins-work/

### Data Folder
"data folder" (as mentioned in the "Information" webpage) or "Data Folder" is a directory reserved by a plugin to store its data.
<br>
It is located in the `plugins` directory.
<br>
Its name is the plugin's name.

### Bukkit Event
"Bukkit Event" is an alias to "event" as mentioned in the webpage.
<br>
Bukkit Events can be provided by plugins, not just Paper.
