## Requirements

Before installing Orderium, you have to meet the following requirements:

- A <Link href="https://papermc.io/software/paper/">Paper</Link> or <Link href="https://papermc.io/software/folia/">Folia</Link> server, or a drop-in replacement (e.g. Purpur);
- <Link href="https://www.spigotmc.org/resources/vault.34315/">Vault</Link> plugin;
- An economy plugin that uses Vault API (e.g. FancyEconomy, EssentialsX, etc.);
- <Link href="https://modrinth.com/plugin/packetevents">packetevents</Link> plugin.

:::tip
Vault plugin by Milkbowl is no longer maintained.
You can use [VaultUnlocked](https://modrinth.com/plugin/vaultunlocked) as a drop-in alternative which is maintained and provides Folia support.
:::

## Downloading

You can download [Orderium on Modrinth](https://modrinth.com/plugin/orderium)!

:::danger[Malicious downloads]
You should **ONLY** download Orderium from Modrinth.
Orderium is only distributed on Modrinth.
Downloads from untrusted sources may contain malicious code.
:::

## Running

After installing Orderium, start your server then execute `plugins` command. If Orderium is in the plugins list and it appears green, it should be ready to use!

## Next steps

Now that the plugin is running, you can start exploring features of Orderium.

One important part that you should do before your server goes into production is to blacklist unobtainable items, though.
