Orderium is a Paper plugin which adds a trading system to your server to enhance the economy.
Orderium is inspired by the Orders system in <Link href="https://donutsmp.net/">DonutSMP</Link>.

## How it works

For now, <Link href="https://donutsmp.wiki/orders#how-it-works">here</Link> is an explanation from a community-maintain DonutSMP wiki (DonutWiki).

There are differences of words in Orderium Docs and the DonutWiki page. This is a map to make it clear:

| Orderium Docs | DonutWiki  |
| ------------- | ---------- |
| "Order owner" | "Buyer"    |
| "Deliverer"   | "Supplier" |
